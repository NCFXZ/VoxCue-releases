# VoxCue

简体中文 | [English](README.en.md)

VoxCue 是一款 Windows / macOS 桌面面试准备助手。围绕简历和职位描述整理资料、准备面试技能，通过实时语音转写、AI 回答与面试记录辅助练习和复盘。

[下载安装包](https://github.com/NCFXZ/VoxCue-releases/releases)

## 主要功能

- **面试准备**：添加简历、职位描述和附件，与 AI 讨论个人经历、项目和目标岗位。
- **技能生成与更新**：根据简历和 JD 整理面试知识与回答要点，逐项查看、选择并保存修改；参考知识与真实个人经历分开处理。
- **AI 服务**：支持连接 ChatGPT 或 GitHub Copilot，由模型按需搜索网页。准备聊天默认不使用知识库，仅在用户明确要求时检索所选资料。
- **实时面试辅助**：分别转写系统音频和麦克风，在置顶浮窗中查看问题与回答，也可输入问题或截图提问。
- **可隐藏悬浮窗**：面试窗口可收起为胶囊，并可开启截图保护，在受支持的截图或屏幕共享中隐藏窗口内容。具体效果取决于操作系统和共享软件。
- **面试记录**：查看转写、回答与截图，支持定位、重命名和导出，方便复盘。
- **个人资料与知识库**：管理个人信息和文档原件，按需进行本地检索；个人资料、面试记录和知识库可分别开启云备份。
- **界面与内容显示**：支持简体中文与 English、浅色与深色及系统外观；聊天和面试回答支持 LaTeX 公式与矩阵。

## 注意事项

- **系统要求**：Windows 10 / 11（64 位）或 macOS 14.2 及以上（Apple Silicon）。
- **账号与用量**：VoxCue 免费提供，AI 功能需要连接相应服务，账号权限与用量限制由该服务决定。可跳过 VoxCue 登录使用本地模式；云备份需要登录 VoxCue。
- **本地组件**：语音识别与文档检索所需组件在应用设置中按需下载。开始面试前请确认音频设备和相关权限可用。
- **数据与隐私**：语音识别在本机运行，不保存或上传原始音频。AI 请求会发送任务所需的文字、相关资料片段，以及主动提交的附件或截图；云备份由用户分别开启。
- **使用统计**：基础统计仅包含有限的操作类别、时间和数值等信息，不包含聊天或转写正文、原始文件、音频、截图或访问令牌。
- **内容核对**：AI 生成的资料和回答可能存在错误，请核对后再保存或使用，避免将参考知识写成自己的真实经历。
