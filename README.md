# VoxCue for Windows

VoxCue 是本地 Windows 桌面面试准备应用，支持 ChatGPT / GitHub Copilot 浏览器登录、准备聊天、个人信息与简历、本地知识库、语音转写和面试记录。

本仓库仅用于安装包和更新文件分发。

## 下载与安装

1. 打开 [最新版本](https://github.com/NCFXZ/VoxCue-releases/releases/latest)。
2. 下载 `VoxCue-Setup-0.2.0-x64.exe` 并运行，按安装向导完成安装。
3. 从桌面或开始菜单打开 **VoxCue**。

适用于 Windows 10/11 x64。安装包包含本地语音、资料处理模型和所需运行库，无需另外安装 Python、Node.js、WSL 或开发工具。首次下载包含模型，文件较大。当前安装包未进行代码签名，Windows 可能显示“未知发布者”。

用户只需下载安装程序 `.exe`；`.blockmap` 和 `latest.yml` 是应用自动更新所用文件。

## 开始使用

1. 登录页选择 **ChatGPT** 或 **GitHub Copilot**，在系统浏览器完成账户授权后回到 VoxCue。可用模型和功能由所选账户的实际权限决定。
2. 在 **个人信息** 中填写姓名、面试语言及相关内容，按需添加简历、职位描述或知识库资料。AI 生成的资料提案需确认后保存。
3. 在准备页输入问题开始聊天；可使用附件、模型和思考强度菜单。聊天、草稿及附件保存在本机。
4. 打开 **设置 → 面试设置**，确认播放设备、麦克风（可选择“不使用麦克风”）、回答模型和思考强度。
5. 点击 **开始面试 → 确认开始**，浮窗自动转写。系统音频为面试官，麦克风为面试者；自动回答仅由系统音频问题触发，也可手动提交或关闭自动回答。
6. 结束后在 **面试记录** 中查看转录和回答，可导出 TXT。

面试回答默认约 60–90 秒口述量，代码使用代码框。浮窗放大显示更多内容，字号保持不变。“附截图”可将问题与当前屏幕一起发送；发送按钮左侧的屏幕截取按钮只发送截图并保留草稿。

音频在本机处理，不保存或上传原音频；必要文字和所选资料片段会发送至所选 AI 服务。启用“附截图”或主动点击屏幕截取时，当前截图也会发送至所选模型，截图不写入磁盘或面试记录。语音识别效果受设备、噪声和语言混读影响，建议使用耳机以减少回录。

## 更新

安装版启动后会检查新版本。也可打开 **设置 → 更新** 检查和下载，然后点击 **重启并更新**。面试进行中无法安装更新。更新保留本机资料、聊天和记录，关闭应用不会自动安装更新。

如果使用旧开发版或便携版，请先手动安装这个安装包；以后使用应用内更新。已经安装同版本旧测试包时，重新运行最新安装程序以替换程序文件。
