# VoxCue

VoxCue 是 Windows / macOS 桌面面试准备应用，支持 ChatGPT 登录、准备聊天、个人资料、本地知识库、语音转写和面试记录。本仓库用于安装包、模型资源和更新文件分发。

## 下载与安装

当前版本：[0.2.2](https://github.com/NCFXZ/VoxCue-releases/releases/tag/v0.2.2)。

| 平台 | 系统要求 | 首次安装 |
| --- | --- | --- |
| Windows x64 | Windows 10 / 11，64 位 | [下载安装程序](https://github.com/NCFXZ/VoxCue-releases/releases/download/v0.2.2/VoxCue-Setup-0.2.2-x64.exe) |
| macOS Apple Silicon | M 系列芯片，macOS 14.2 及以上 | [下载 DMG](https://github.com/NCFXZ/VoxCue-releases/releases/download/v0.2.2/VoxCue-0.2.2-arm64.dmg)，打开后将 VoxCue 拖入 Applications |

Windows 仅为当前用户安装。首次安装默认位于 `%LOCALAPPDATA%\Programs\VoxCue`，可以选择其他位置；检测到已有版本时保留原目录，“选择”按钮置灰。

Windows 安装包未进行 Authenticode 签名，可能显示“未知发布者”。Mac 使用 ad-hoc 签名，未经过 Apple 公证，首次打开可能需要在“系统设置 → 隐私与安全性”中明确允许；当前不提供 Intel Mac 版本。

`.blockmap`、`latest.yml`、Mac 的自动更新 ZIP 和 `latest-mac.yml` 供应用更新使用，首次安装无需下载这些文件。带 `previous` 字样的附件为历史备份，请使用上表中的当前下载入口。

本次更新了同一版本的 Windows 安装包，修复开始安装后停在 0% 的问题，补齐安装目录选择和卸载数据选项。Mac 0.2.2 安装文件保持不变。

## 开始使用

1. 通过系统浏览器完成 ChatGPT 授权，再回到 VoxCue。可用模型和功能由账户权限决定。
2. 在“个人信息”中填写资料，按需添加简历、职位描述或知识库；AI 生成的资料提案需确认后保存。
3. 在准备页开始聊天，可使用附件、模型和思考强度菜单。聊天、草稿及附件保存在本机。
4. 在“设置 → 本地组件”下载语音与知识库模型。应用负责下载和校验，后续启动及升级复用未变化的缓存；安装包不内嵌模型，无需另装 Python、Node.js 或 WSL。
5. 在“设置 → 面试设置”确认播放设备、麦克风及回答设置，再开始面试。系统音频用于提问，麦克风用于面试者转写；结束后可查看并导出面试记录。

登录和准备聊天无需先下载本地模型；语音模型就绪后才能开始面试，知识库模型就绪后才能创建或选择知识库。

## 更新与卸载

在“设置 → 更新”检查和下载新版本，然后明确点击“重启并更新”。面试进行中无法安装更新；关闭应用不会自动安装。Windows 与 Mac 使用独立更新文件，放在同一发行页不会混用安装包。

Windows 卸载默认勾选“保留用户数据”。取消勾选并点击卸载，会直接删除应用内的聊天、资料、知识库、设置和模型缓存，无二次确认；外部原始文件保留。应用更新始终保留用户数据。

## 数据与隐私

音频在本机处理，不保存或上传原音频；必要文字和所选资料片段会发送至 ChatGPT。开启“附截图”或主动截取屏幕时，截图会发送至所选模型，不写入磁盘或面试记录。识别效果受设备、噪声及语言影响，建议使用耳机减少回录。
